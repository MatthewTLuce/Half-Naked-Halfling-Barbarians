The core contract

Player action → DM proposal → structural checks → independent human acceptance → canonical event log. Rejected proposals remain evidence. The model cannot silently repair history or grade its own work.

Facts, possessions, knowledge, geography, rulings and unresolved consequences persist outside conversational memory. Interruptions invalidate pending proposals; corrections append explicit compensating changes.

What the result establishes

The ledger survived session boundaries and restarts; stale and contradictory changes were rejected; an independent reader reproduced the canonical state and detected the seeded false claims. These are tests of the instrument, not evidence that an AI can sustain a coherent campaign.

Live play needs complete character sheets, selected pages from the ingested SRD corpus, an explicitly selected model, experienced players and independent human review. The API adapter is included and mock-tested. Semantic knowledge leaks, plausible consequences, improvisation and overall coherence remain human judgments.

The API key is stored separately in the approved workspace configuration. It is not part of this handoff or any exported campaign.
