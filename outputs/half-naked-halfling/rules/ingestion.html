## Meaning of ingestion

The DM can receive source pages through `hnh.py rules --pages ... --reviewer ...`. That selection is permanently logged and present in subsequent DM context and request traces. The independent evaluator receives the same logged packet. No memory-only assumption is required.

An ingestion pass does not prove that all rules are correctly interpreted or automated. Search can miss synonyms and related exceptions. Extracted tables or hyphenated terms may require visual checking. The unchanged PDF resolves ambiguity. No source instructions are executed, no existing campaign history was rewritten, and no live API request was made.
